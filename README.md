# Gridx

一マスに集中し、全体を見失わない模写練習アプリ。

## 画面構成
1. ギャラリー：複数画像・フォルダーを読み込み、写真を一覧から選択
2. グリッド：選択した写真に格子を表示して模写に集中

## 操作
- 写真カードを選ぶとグリッド画面へ移動
- 「ギャラリーに戻る」で写真一覧へ戻る
- グリッド上のマスをタップすると選択／解除。複数選択したマスはすべて明るく表示
- 初期状態では全マスが暗く、タップしたマスだけ明るく表示
- 選択中のマスをもう一度タップすると選択解除でき、全マス未選択にも戻せる
- 格子線はドラッグして移動
- 選択マスをまとめて完了として記録
- 非選択マスの明るさは10% / 20% / 30%で変更（初期値10%）
- 初期グリッドは短辺を3分割した正方形基準。正方形画像では3×3

写真はブラウザ内で処理し、外部サーバーへ送信しません。v10からは、読み込みに成功した写真と練習の進捗をこの端末内に保存します。


## ドラッグ＆ドロップ
- MacのFinderから画像ファイル・複数画像・フォルダーをギャラリーのドロップエリアへドラッグ＆ドロップできます
- フォルダーをドロップした場合は、中の階層をたどって画像ファイルを探します
- 画像以外のファイルは追加しません
- ブラウザーがフォルダーのドラッグ＆ドロップに対応していない場合は「フォルダーを読み込む」ボタンを使ってください


## Mac Safari 読み込み修正
- SafariがファイルのMIMEタイプを空欄や汎用値で返す場合に備え、拡張子でも画像判定
- JPEG / PNG / GIF / WebP / HEIC / HEIF / AVIF / TIFF / BMP を判定対象に追加
- 読み込めなかった場合にメッセージを表示


## 写真の移動
- グリッド画面に「前の写真」「次の写真」「ランダム」ボタンを配置
- 前／次はギャラリーの並び順で移動し、端まで進むと反対側へ循環
- ランダムは現在表示中の写真を除外して、別の写真を選択
- 写真が1枚だけの場合は移動ボタンを無効化


## 画像ファイルのみ読み込み
- ファイル選択・フォルダー読み込みの選択候補を画像形式に限定
- ドラッグ＆ドロップを含むすべての読み込み経路で画像かどうかを確認
- 拡張子だけを画像に偽装したPDFなども、ブラウザーで画像としてデコードできなければ追加しない
- 読み込めないファイルや画像以外は除外し、必要に応じて件数を通知


## 端末内ライブラリ（v10）
- 読み込みに成功した画像をIndexedDBへ保存し、次回起動時にギャラリーへ復元
- SHA-256で画像の中身を照合し、ファイル名やフォルダーが違っても同一データは重複登録しない
- 同じ画像でも編集・再圧縮などでファイル内容が変わった場合は別画像として扱う
- iCloud未ダウンロードなど読み込み不可のファイルは個別にスキップし、フォルダー内のほかの写真の読み込みを続行
- 写真ごとに行・列、格子線位置、完了マス、暗さ設定を保存
- ギャラリーから端末内に保存した写真を個別削除
- 端末内保存が利用できない場合も、今回の起動中は読み込んだ写真を利用可能
- ブラウザーのデータ消去、サイトデータ削除、端末変更などで保存内容が失われる可能性があるため、元画像の保管を推奨


## 画像の表示サイズ調整（v11）
- ギャラリーのサムネイルは画像全体を表示し、正方形枠で切り抜かない
- グリッド画面では画像の縦横比を保ったまま、表示領域の幅と高さに合わせて縮小
- ウィンドウサイズや画面の向きが変わった場合も再フィット


## ギャラリー表示・削除（v12）
- サムネイルは正方形の枠内に全体を収め、縦横比を保ったまま表示
- ギャラリーのチェックボックスで写真を複数選択
- 「すべて選択」「選択を削除」「全削除」を利用可能
- 削除はGridxの端末内ライブラリだけに適用し、元の写真ファイルは削除しない


## v13
- ギャラリーのカード外枠に幅制限を追加し、元画像のサイズに引っ張られて横にはみ出す問題を修正
- 選択チェックボックスをカード左上に重ねて配置
- カード内の画像とファイル名をカード幅内に収める


## v14
- グリッド画面で「選択モード：ON / OFF」を切替可能に変更。OFFではマスのタップ選択を停止し、表示中の選択状態を固定
- 写真を切り替えるたびに一時的な選択マスを即時リセットし、前の写真の選択が次へ引き継がれないよう修正
- 画像読み込み後の表示サイズ調整処理を追加。画像の縦横比を保ち、画面幅と高さに合わせて表示
- 画像切替中は新しい写真の準備ができるまでステージを隠し、前の写真が一瞬残る見た目を抑制
- ヘッダーの「Gridx」を押すとギャラリー（ホーム）へ戻る
