# Gridx

一マスに集中し、全体を見失わない模写練習アプリ。

## 画面構成
1. ギャラリー：複数画像・フォルダーを読み込み、写真を一覧から選択
2. グリッド：選択した写真に格子を表示して模写に集中

## 操作
- 写真カードを選ぶとグリッド画面へ移動
- 「ギャラリーに戻る」で写真一覧へ戻る
- グリッド上のマスをタップすると選択／解除。複数選択したマスはすべて明るく表示
- 最後の1マスは選択状態を維持
- 格子線はドラッグして移動
- 選択マスをまとめて完了として記録
- 10% / 20% / 30%で周囲の暗さを変更

写真はブラウザ内で処理し、外部サーバーへ送信しません。再読み込みすると写真と進捗は消えるため、再度読み込んでください。


## ドラッグ＆ドロップ
- MacのFinderから画像ファイルをギャラリーのドロップエリアへドラッグ＆ドロップして追加できます
- 複数ファイルを一度にドロップできます
- フォルダーそのもののドロップはブラウザ依存のため、フォルダー読み込みボタンも残しています
