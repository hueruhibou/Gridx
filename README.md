# Gridx

一マスに集中し、全体を見失わない模写練習アプリ。

## 画面構成
1. ギャラリー：複数画像・フォルダーを読み込み、写真を一覧から選択
2. グリッド：選択した写真に格子を表示して模写に集中

## 操作
- 写真カードを選ぶとグリッド画面へ移動
- 「ギャラリーに戻る」で写真一覧へ戻る
- グリッド上のマスをタップすると選択／解除。複数選択したマスはすべて明るく表示
- 最後の1マスは選択状態を維持
- 格子線はドラッグして移動
- 選択マスをまとめて完了として記録
- 10% / 20% / 30%で周囲の暗さを変更

写真はブラウザ内で処理し、外部サーバーへ送信しません。再読み込みすると写真と進捗は消えるため、再度読み込んでください。


## ドラッグ＆ドロップ
- MacのFinderから画像ファイルをギャラリーのドロップエリアへドラッグ＆ドロップして追加できます
- 複数ファイルを一度にドロップできます
- フォルダーそのもののドロップはブラウザ依存のため、フォルダー読み込みボタンも残しています


## Mac Safari 読み込み修正
- SafariがファイルのMIMEタイプを空欄や汎用値で返す場合に備え、拡張子でも画像判定
- JPEG / PNG / GIF / WebP / HEIC / HEIF / AVIF / TIFF / BMP を判定対象に追加
- 読み込めなかった場合にメッセージを表示


## 写真の移動
- グリッド画面に「前の写真」「次の写真」「ランダム」ボタンを配置
- 前／次はギャラリーの並び順で移動し、端まで進むと反対側へ循環
- ランダムは現在表示中の写真を除外して、別の写真を選択
- 写真が1枚だけの場合は移動ボタンを無効化
