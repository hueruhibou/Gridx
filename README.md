# Gridx
一マスに集中し、全体を見失わない。模写練習向けのローカル処理PWA試作。

## 試作機能
- 写真をブラウザ内で読み込み（サーバー送信なし）
- 縦横の分割数を個別指定（1〜12）
- 3×3〜8×8プリセット
- 格子線をドラッグして区画幅・高さを個別調整
- 選択区画100%、周囲10%・20%・30%から選択（初期値20%）
- 区画をタップして自由に選択
- 完了区画をセッション中に記録

## 公開
GitHub Pagesの場合、Settings → Pages → Deploy from a branch → main / (root)。

## 制限
進捗の永続保存は未実装。写真はページを閉じると再読み込みが必要。端末や画像サイズにより性能は変わります。


## ファイル構成
- `index.html`：画面とレイアウト
- `app.js`：格子・選択・進捗などのアプリ処理
- `manifest.webmanifest`：ホーム画面追加用のPWA設定
- `sw.js`：アプリ本体のキャッシュとオフライン表示
- `icon.svg` / `icon-192.png` / `icon-512.png` / `apple-touch-icon.png`：アプリアイコン

GitHub Pagesには、このフォルダ内のファイルをすべてリポジトリ直下へアップロードしてください。
